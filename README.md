# ScrollFlow
 
Lightweight Auto-Scroll for macOS
一款极简轻量的 macOS 自动滚动小工具
 
简介 | About
 
ScrollFlow 专为 macOS 设计，主打轻量、纯净、后台静默运行。
用于网页、小说、长文档、信息流自动滚动浏览，替代高价同类付费软件。
 
A simple & lightweight auto-scroll menu bar app for macOS.
Built for reading web pages, novels, long documents and feeds.
